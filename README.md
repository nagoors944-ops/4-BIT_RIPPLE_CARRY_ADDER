## WEEK-2 TASK DESCRIPTION
1.I implemented a 4-bit Ripple Carry Adder using Verilog HDL.
  It adds two 4-bit binary numbers, A and B, along with an initial carry input Cin, and produces a 4-bit sum Sum and a final carry output Cout.
  I wrote the Verilog design code and testbench in Vivado. 
  I observed the output waveforms and verified the results against the expected binary addition values.

2. I learned how to design a 4-bit Ripple Carry Adder using Verilog HDL.
  I understood how carry propagates from one full-adder stage to the next.
  I learned how to write a testbench and apply different input combinations.
  I understood how synthesis converts RTL code into a gate-level netlist.
  I learned how to run simulation and observe input and output waveforms in Vivado.
  I verified that the simulated sum and carry outputs matched the expected results.
  I understood that carry propagation introduces delay in a Ripple Carry Adder.
